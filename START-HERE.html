社長にお願いしたいこと

公開の設定や、さくらインターネットのサーバー作業はすべて日本信達側でやります。社長にお願いしたいのは次の3つだけです。

  1. GitHub のアカウントを取る（別途ご案内します。サイトのデータを保管する場所で、無料です）
  2. サイトの中身を見て、古くなっているところを直す（住所・電話番号・品種・収穫時期など）
  3. これから先、お知らせや文章の更新を Codex に頼んで進める

手順

  1. GitHub の招待を承認する

    日本信達から GitHub の招待メール（件名に nihonshintatsu-byte/tomapufarm-web と入っています）が届きます。メールの View invitation を押し、開いた画面で Accept invitation を押してください。

  2. Codex を開いて、最初の一言を伝える

    Codex を開き、こう頼んでください。

    GitHub の nihonshintatsu-byte/tomapufarm-web をこのパソコンに取り込んで（clone して）、中の HANDOFF.md を実行してください。

    サイトのデータの中に、Codex 向けの手順書（HANDOFF.md）が入っています。Codex がそれを読んで、サイトを画面に表示するところまで進めます。途中で「Git」「Node.js」「GitHub CLI」を入れてくださいと言われたら、案内どおりに入れてください。インストーラーを実行するだけです。ブラウザに GitHub のログイン画面が出たら、ご自身のアカウントでログインしてください。

  3. 画面を見て、直したいところを伝える

    ブラウザに新しいサイトが表示されます。会社概要・代表挨拶・農作物の品種や収穫時期など、いまの実態と違うところを見つけたら、そのまま Codex に伝えてください。

    about ページのとうもろこしの時期を「8月下旬〜9月」に直してください。

  4. 公式サイトに出す

    直した内容でよければ「これで公開してください」と伝えてください。Codex が確認の手順を通してから反映し、数分で公式サイトに出ます。

これから先の使い方

これから先は、次のように頼むだけで更新できます。Codex が変更を用意し、社長が「これでよい」と確認すると、数分で公式サイトに出ます。

お知らせを追加する

お知らせを1本追加してください。
日付は 2026年6月1日、タイトルは「さくらんぼの予約受付をはじめました」。
本文は「今年もさくらんぼの予約を受け付けます。発送は6月下旬からです。」
写真は デスクトップの cherry.jpg を使ってください。

文章を直す

代表挨拶の3段落目を、いまの言葉に直したいです。
「〜」という内容に書き換えてください。

写真を差し替える

お知らせ「ひまわりGARDEN」の写真を、デスクトップの himawari2026.jpg に差し替えてください。

迷ったら、やりたいことをそのまま日本語で伝えてください。Codex が分からないときは聞き返します。

これだけはお願いします

  • デザインは変えないようにしています。「色を変えたい」「並びを変えたい」といった希望があるときは、まず日本信達にご相談ください
  • うまくいかないときは、そのまま進めないでください。エラーが出たら画面をそのまま送っていただければ、こちらで見ます
  • Codex が「本番に反映しました」と言っても、実際に公式サイトへ出るのは確認の手順を通ったあとです。すぐ反映されないのは正常です
