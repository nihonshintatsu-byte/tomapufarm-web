## 確認方法

既存のCSSを使用した本文確認用プレビュー。公式サイトのヘッダー・フッターや一覧のページ送りは省略している。
表示用データは posts.json。番号別Markdownは確認用の原稿控えで、修正時には両方の内容を揃える。
このフォルダーはAstroの公開対象外。確定・承認後にsrc/content/newsへ記事を移す。
